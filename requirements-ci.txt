# Dependencies for the portable (non-RL) test suite.
#
# `requirements.txt` is the *research* environment: it pulls bitsandbytes, trl, peft,
# datasets, wandb and two CLIP packages, and it does not contain torch at all — the
# README installs that separately from a CUDA-specific index. None of that is needed to
# test repository profiling, the sandbox runner, evidence capture or the bug report, and
# most of it will not install cleanly on a CPU-only CI runner.
#
# This file is therefore not a subset chosen by taste. It is the set that was found by
# building a clean virtualenv and adding packages until
#
#     pytest -m "not requires_torch and not requires_docker and not requires_browser"
#
# collected and passed: 694 passed, 5 skipped, 25 deselected. Every entry below is here
# because removing it produced a collection error, and the comment says which component
# needs it.
#
# The deep-learning stack is deliberately absent. Tests that need it are marked
# `requires_torch` and are not collected when it is missing — see `tests/conftest.py`.
